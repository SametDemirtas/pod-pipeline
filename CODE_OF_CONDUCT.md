# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part in its issues, pull requests and discussions is expected to keep to it.

## Reporting

Report unacceptable behaviour privately to the maintainer, through the contact details on their
GitHub profile, rather than in a public issue. Every report is read and answered, and the
reporter's identity is kept private.
